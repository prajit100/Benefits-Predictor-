# CyberSecure Snapshot

CyberSecure Snapshot is a lightweight, browser-based cybersecurity readiness assessment. It guides teams through key questions and delivers control-level recommendations aligned to frameworks like NIST and CIS.

View your app in AI Studio: https://ai.studio/apps/drive/1Nn9aqlyxT0oaRUQfiEvch5K3-5Nx9nKX

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
